## AI Use
AI tools are encouraged as a work-aid to support learning and problem solving; however, blindly copying and pasting AI generated code should not be passed off as genuine work. **All uses of AI must be declared with assignment submissions.**(ChatGPT, Copilot,etc)
**Additionally, students must use code comments to cite any instances where AI-generated code is utilized throughout their project files.**A short comment immediately above the generated block is sufficient. If suspected there is a failure to report AI generated code due to improper understanding, modification, or attribution will trigger a formal review. If students are found using unoriginal AI generated code as their own, they will be subject to failure on the assignment and further disciplinary action in accordance with Drexel's academic honesty policy.
